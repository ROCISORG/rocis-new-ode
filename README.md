# ROCIS Outdoor Data Explorer

The new Outdoor Data Explorer for ROCIS (Reducing Outdoor Contaminants in Indoor Spaces).
It shows the outdoor Dylos particle monitor data for every published cohort, plus guides on
reading the data. It replaces the explorer at <https://rocis.github.io/explorer.html>.

This is a static site: plain HTML and JavaScript with no build step. The charts use
[Apache ECharts](https://echarts.apache.org/) 5.6.0, loaded from cdnjs.
